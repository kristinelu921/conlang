## Changed Hyperparameters

The paper reports 1600 batches of 8, alpha 0.5, and two H100 GPUs. Its seed is not recorded. The original parallel script uses batch 8 per process and accumulation 2 (effective batch can be 32 on two processes). This reproduction explicitly uses global batch 8 and 1600 optimizer updates. These conventions are not silently treated as identical.

The new TPU implementation follows Algorithm 1's sampled corrupted input. Original scripts instead run entire generated trajectories. Other explicit corrections: KL remains differentiable, uses matching sequence coordinates and token normalization; CE uses the checkpoint's shifted logits; padding is excluded; each progressive stage resets its optimizer and counters while taking its teacher from the completed parent. The initial three legacy trainers received a narrower KL repair, but are not the launch entry point and have remaining legacy limitations.

## Failure Details

- No original failure logs or original trained checkpoints supplied.
- Original parallel trainer stores `logits.detach().cpu()` before KL, eliminating its gradient.
- Original trainers independently filter teacher/student masked coordinates, then truncate to equal count; coordinates can differ.
- Original `reduction='mean'` averages KL over vocabulary entries as well as tokens.
- Original AR perplexity script scores self-generated text; diffusion metric uses a confidence-dependent teacher-forced schedule. Their raw values are not directly comparable likelihoods.
- Default ELF environment bootstrap requires an unrelated `.netrc`; it was not used. Isolated setup initially hit a package-index resolution conflict, corrected by explicitly resolving trusted PyPI and PyTorch CPU indexes.
